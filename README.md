📊 Data Redundancy Detection System 

📌 Overview

This project is a Python + MongoDB based system designed to detect and prevent duplicate data entries. It ensures that only unique records are stored in the database, improving data integrity and efficiency.

🎯 Objective

- Prevent duplicate data insertion
- Maintain clean and consistent database records
- Improve storage efficiency

🛠️ Technologies Used

- Python
- MongoDB Atlas
- PyMongo


⚙️ Working

- Connects Python with MongoDB Atlas
- Accepts data input (name, age)
- Checks if data already exists in collection
- Inserts only unique records
- Rejects duplicate entries


💻 Output Example

Inserted successfully  
Inserted successfully  
Inserted successfully  
❌ Duplicate data found. Not inserted.


📌 Key Learning

- MongoDB integration with Python  
- CRUD operations  
- Duplicate data handling logic  
- Database management basics
